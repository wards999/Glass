# M0 — Skeleton: results

**Date:** 2026-11-19 · **CI run:** 44638429945 (all green on first run)

## What works
- Cargo workspace: `core`, `app-win`, `tools/losssim`.
- `core` builds as rlib + staticlib on Linux, Windows (MSVC) and macOS (arm64).
  - `protocol`: draft v0 24-byte video packet header with encode/decode (no allocation).
  - `stats`: fixed-size per-frame stage timestamps.
  - `ffi`: `glass_core_version()`, `glass_protocol_version()`; header generated by
    cbindgen and checked in (CI fails if stale).
- `app-win`: Rust binary linking core; prints versions.
- `app-mac`: SwiftPM package; `GlassKit` links `libglass_core.a` via a C module map;
  `GlassMac` executable prints versions; XCTest calls core over the C ABI.
- CI: three jobs (see below).

## Known issues / next
- `app-mac` is a SwiftPM command-line package, not a signed `.app` bundle. M3b needs
  a bundle for the Screen Recording and Accessibility permissions (ADR 0001).
- You have to run `cargo build -p glass-core --release` before `swift build`.
- Apple Silicon only. No universal lib.
- Unit tests for FEC, the replay window and key derivation arrive with those features
  (M4 and M6).
